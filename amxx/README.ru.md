# Заметки AMXX / Pawn

[EN](README.md) | [UK](README.uk.md) | [RU](README.ru.md)

Заметки по написанию плагинов AMXX: работа с игроками, командами, меню, хуками и данными. В каждой теме разбираем, что делает код и какая незаметная деталь может изменить результат.

За основу взят AMXX 1.9. Если для примера нужны ReAPI или определённая игра, это указано рядом с ним.
