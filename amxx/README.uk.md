# Нотатки AMXX / Pawn

[EN](README.md) | [UK](README.uk.md) | [RU](README.ru.md)

Нотатки про написання плагінів AMXX: робота з гравцями, командами, меню, хуками й даними. У кожній темі розбираємо, що робить код і яка непомітна деталь може змінити результат.

За основу взято AMXX 1.9. Якщо для прикладу потрібні ReAPI або певна гра, це зазначено поруч із ним.
