# DevNotes

Личная база полезных заметок по PHP и разработке модулей AMXX.

Здесь собраны короткие примеры, готовые функции, справочные значения и пояснения, к которым удобно возвращаться во время работы.

- [Возможности PHP 7.4-8.5](php/php_7.4-8.5.md) - практический справочник по новым возможностям языка и встроенных модулей.
- [Полезные функции](php/notes.md) - небольшие готовые решения для строк, массивов и ответов сервера.
- [Описание раздела](php/README.md)

## AMXX

- [Полезные функции](amxx/functions.md) - заготовки для игроков, оружия, сущностей, сообщений и эффектов.
- [Смещения памяти](amxx/offsets.md) - справочные значения для работы с внутренними полями игровых сущностей.
- [Описание раздела](amxx/README.md)

## Важно

Примеры рассчитаны прежде всего на использование как личные рабочие заметки. Перед переносом в готовый проект проверяйте зависимости, версию PHP, версию AMXX, сборку игрового сервера и актуальность смещений памяти.
