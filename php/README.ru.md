<a id="examples"></a>
## Как читать примеры

Каждый блок кода независим, если текст прямо не указывает другого. Скопируйте PHP-пример в файл после открывающего тега `<?php`; не объединяйте все примеры в один скрипт. Имена классов и функций могут намеренно повторяться.

Метка версии указывает появление основной возможности. Если в разделе используется более позднее дополнение, это объясняется в тексте. Для примеров, зависящих от окружения, указаны требования к HTTP, базе данных, файлам или расширениям. Ожидаемый результат может быть комментарием в коде.

<a id="extensions"></a>
## Ядро и расширения

Одной версии PHP недостаточно, чтобы гарантировать наличие всех расширений. Например, mbstring, intl, curl и драйверы БД зависят от установки. Функция также может требовать определённой возможности внешней библиотеки. Зависимости указаны в соответствующей главе.

<a id="run"></a>
## Локальный запуск

```console
php -v
php -m
php --ri mbstring
php -l example.php
php example.php
```

Перед выполнением примера проверьте интерпретатор, расширения и синтаксис. Lint проверяет синтаксис, но не подтверждает соединение с БД, поведение HTTP или наличие каждой вызываемой функции.

<a id="scope"></a>
## Границы справочника и источники

Эта редакция охватывает полезные дополнения PHP 7.0-8.5. Некоторые более старые возможности приведены как контекст для новых. Composer-пакеты и API фреймворков сюда не входят. Возле каждой возможности есть ссылка на документацию PHP или официальный RFC.

Редакция справочника: 1.0.0. Проверка материала: 22 октября 2026 года. Это первая расширенная редакция, а не перечень всех функций или исправляющих выпусков PHP. Доступность возможности и поддержка старой ветки PHP являются разными вопросами.
