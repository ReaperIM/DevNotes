<a id="examples"></a>
## Як читати приклади

Кожен блок коду незалежний, якщо текст прямо не вказує іншого. Скопіюйте PHP-приклад у файл після відкривального тегу `<?php`; не об'єднуйте всі приклади в один скрипт. Назви класів і функцій можуть повторюватися навмисно.

Позначка версії вказує появу основної можливості. Якщо в розділі використано пізніше доповнення, це пояснено в тексті. Для прикладів, що залежать від оточення, вказано вимоги до HTTP, бази даних, файлів чи розширень. Очікуваний результат може бути коментарем у коді.

<a id="extensions"></a>
## Ядро та розширення

Самої версії PHP недостатньо, щоб гарантувати наявність усіх розширень. Наприклад, mbstring, intl, curl і драйвери БД залежать від установлення. Функція також може потребувати певної можливості зовнішньої бібліотеки. Залежності вказано у відповідній главі.

<a id="run"></a>
## Локальний запуск

```console
php -v
php -m
php --ri mbstring
php -l example.php
php example.php
```

Перед виконанням прикладу перевірте інтерпретатор, розширення та синтаксис. Lint перевіряє синтаксис, але не підтверджує з'єднання з БД, поведінку HTTP чи наявність кожної викликаної функції.

<a id="scope"></a>
## Межі довідника та джерела

Ця редакція охоплює корисні доповнення PHP 7.0-8.5. Дещо зі старіших можливостей наведено як контекст для нових. Composer-пакети та API фреймворків сюди не входять. Біля кожної можливості є посилання на документацію PHP або офіційний RFC.

Редакція довідника: 1.0.0. Перевірка матеріалу: 22 жовтня 2026 року. Це перша розширена редакція, а не перелік усіх функцій чи виправних випусків PHP. Доступність можливості та підтримка старої гілки PHP є різними питаннями.

- [Офіційні посібники з міграції](https://www.php.net/manual/en/appendices.php)
- [Підтримувані версії PHP](https://www.php.net/supported-versions.php)
